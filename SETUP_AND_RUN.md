## 1. Technology Stack

- **Runtime & Language:** Python 3.11+
- **Web Framework:** FastAPI (with Uvicorn server)
- **Data Validation & Schemas:** Pydantic v2
- **Large Language Model:** Google Gemini (`google-genai` SDK)
- **Search & Retrieval:** `scikit-learn` (TF-IDF Vectorizer with Cosine Similarity, Top-4 Chunks)
- **Frontend Interface:** Vanilla HTML5, CSS3 (Modern Responsive Dual-Pane Layout), Plain JavaScript
- **Alternative UI:** Streamlit (`support-agent/app.py`)

## 2. Quickstart: How to Run in Under 5 Steps

### Step 1: Clone the repository
```bash
git clone https://github.com/kunj2210/AI_Agent.git
cd AI_Agent
```

### Step 2: Create and activate a virtual environment
```bash
python -m venv venv

# On Windows (PowerShell):
venv\Scripts\activate

# On macOS / Linux:
source venv/bin/activate
```

### Step 3: Install dependencies
```bash
pip install -r requirements.txt
```

### Step 4: Configure environment variables
Create a `.env` file in the project root or in `support-agent/`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.5-flash-lite
TEMPERATURE=0.2
```
*(You can obtain a free API key from [Google AI Studio](https://aistudio.google.com/)).*

### Step 5: Start the application
Run the FastAPI application from the project root:
```bash
python main.py
```
*Or with uvicorn directly:*
```bash
uvicorn main:app --reload --port 8000
```
Open your browser and navigate to **http://127.0.0.1:8000**.

#### Optional: Run Streamlit UI
If you prefer testing with Streamlit:
```bash
streamlit run support-agent/app.py
```
Open **http://localhost:8501** in your browser.

## 4. Using the Web Application

The web interface is divided into two primary views accessible via the top navigation bar:

### A. Chat View (`http://127.0.0.1:8000`)
- **Customer Chat Panel (Left):**
  - Natural conversation interface where customers can type inquiries.
  - Multi-turn conversation history is maintained for context.
  - Includes a **Clear History** button to reset the dialogue.
- **Structured JSON Inspector (Right):**
  - Displays the live, pre-formatted Pydantic JSON triage object generated by the backend on every single turn.
  - Displays **4 Parallel Triage Badges** directly below the JSON:
    - 📁 **Category:** (`delivery`, `refund`, `billing`, `account_access`, `technical_support`, `other`)
    - ⚡ **Priority:** (`low`, `medium`, `high`, `critical`)
    - 🎭 **Sentiment:** (`neutral`, `calm`, `frustrated`, `angry`)
    - 🛡️ **Escalation:** (`Yes` or `No`, plus dynamic warnings for `⚡ Policy Conflict` or `🛡️ Injection Blocked`).
- **Responsive Layout:**
  - On desktop, the chat and JSON inspector sit side-by-side (60/40 split).
  - On tablet and mobile devices (`≤ 880px`), the layout stacks vertically with touch-friendly elements.

### B. Admin Config & Knowledge Base View
- **Agent Settings & Support Rules:**
  - Live edit the **Agent Role**, **Tone of Voice**, **Supported Topics**, **Escalation Rules**, and **Response Boundaries**.
  - Click **Save Configuration** to update rules instantly without restarting the server.
  - Click **Reset to Defaults** to restore the default configuration.
- **Knowledge Base Document Manager:**
  - Upload `.md` or `.txt` policy files directly through the browser.
  - View all currently indexed knowledge base documents.
  - Delete documents with one click.
  - Any upload or deletion immediately triggers automatic TF-IDF re-indexing.

## 5. REST API Endpoints Reference

| Method | Endpoint | Description | Request Body / Params |
|---|---|---|---|
| `GET` | `/` | Serves the interactive HTML5 application | None |
| `POST` | `/api/chat` | Executes multi-turn triage and returns structured JSON | `{"message": "...", "history": [...]}` |
| `GET` | `/api/config` | Reads current runtime configuration from `config.json` | None |
| `POST` | `/api/config` | Live-updates agent persona and business rules | Full or partial config JSON object |
| `POST` | `/api/config/reset` | Resets agent rules to factory defaults | None |
| `GET` | `/api/kb` | Lists all indexed knowledge base document filenames | None |
| `POST` | `/api/kb/upload` | Uploads a `.txt` or `.md` file and re-indexes search | Multipart Form (`file: UploadFile`) |
| `DELETE` | `/api/kb/{filename}` | Deletes a document and re-indexes search | Path parameter: `filename` |

## 7. Troubleshooting & FAQ

### Q: Getting `429 Resource Exhausted` from Gemini API?
**A:** Free-tier Gemini keys have daily RPM/RPD limits (e.g., 20 requests per day on certain models). The agent includes automated model fallback in [`llm.py`](file:///c:/Users/kunj%20lunagariya/OneDrive/Desktop/Chatbot/support-agent/llm.py) that rotates between `gemini-3.5-flash-lite`, `gemini-2.5-flash`, and `gemini-3.8-flash`. You can also configure a fresh key from [Google AI Studio](https://aistudio.google.com/).

### Q: Port 8000 is already in use?
**A:** Run with a custom port:
```bash
uvicorn main:app --reload --port 8080
```

### Q: How do I test policy conflicts?
**A:** In the Chat View, send the query:  
`"I want to return an item purchased 20 days ago. Is that allowed under your return window?"`  
Observe the right panel: `policy_conflict_detected` will be `true`, priority will elevate to `high`, and the badge `⚡ Policy Conflict` will illuminate.
